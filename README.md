# AIAG (Agent IAG) - Conversational Insurance Assistant

This is a Rasa-powered chatbot that helps customers get personalized insurance product recommendations.

### Setup:
```bash
pip install rasa
rasa train
rasa run actions &
rasa shell
```

### Future Improvements:
- Add support for travel, home, and life insurance
- Integrate with ML-based recommendation engine
- Deploy on web using Rasa Webchat or Botfront
